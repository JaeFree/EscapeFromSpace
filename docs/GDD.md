## 1. 개요

우주인이 되어 버려진 우주정거장에 들어가 물자를 챙기고, 보안 로봇을 피하거나 파괴하며, 산소가 떨어지기 전에 탈출 포드까지 살아 나가는 1인용 탑다운 슈터.

- 한 줄 컨셉: "챙길수록 무거워지고, 산소는 줄어든다."
- 세계관: 연락이 끊긴 채 궤도를 떠도는 연구 정거장. 플레이어는 회수 업자 우주인으로, 정거장에 도킹해 아직 작동 중인 보안 로봇을 피해 값나가는 화물을 회수한다.
- 아트: 기능 개발이 끝날 때까지는 단색 도형으로 개발한다. 디자인과 색은 기능 완성 후 요소별로 하나씩 정한다.

## 2. 기획 의도와 핵심 재미

핵심 재미는 "지금 나갈까, 하나 더 챙길까"를 계속 고민하게 만드는 긴장감이다. 죽으면 가지고 들어간 것까지 잃는다.

- **위험과 보상**: 가치 높은 연구 컨테이너는 보안 로봇이 지키는 연구 구역에 둔다. 가방이 무거워지면 이동이 느려져 탈출이 어려워진다.
- **전투 손맛**: 적은 적지만 한 발이 아프다. 구역마다 로봇 수가 다르고, 로봇이 든 무기에 따라 들어오는 피해가 다르다. 재장전과 구르기 쿨타임이 겹치는 순간이 가장 위험하다.
- **산소 압박**: 우주복 산소는 기본 8분. 바닥나면 질식 피해(도트 데미지)를 입는다.

## 3. 핵심 게임 루프

1. **대기실 창고**: 장비를 고르고 저장한다.
2. **정거장 도킹(진입)**: 산소가 줄기 시작한다.
3. **루팅**: 컨테이너를 열고 가방 칸과 무게를 관리한다.
4. **교전**: 로봇을 발견하면 교전하고, 정리되면 다시 루팅으로 돌아간다. (3 ↔ 4 반복)
5. 끝나는 방법은 두 가지다.
   - **탈출 성공**: 탈출 포드 안에서 5초를 버티면 가방과 장비를 가지고 대기실 창고로 돌아간다.
   - **사망**: HP가 0이 되면(질식 포함) 보관함 1칸을 제외한 모든 것을 잃고 대기실 창고로 돌아간다.

한 판은 4~6분을 목표로 한다.

## 4. 전투 시스템

무기 5종은 사거리와 위험을 맞바꾸는 구조다. 가까이 붙을수록 초당 피해(DPS)가 높고, 멀리서 쏠수록 한 발은 세지만 느리다.

### 4.1 규칙

1. **사격 판정**: 히트스캔. 클릭 순간 총구에서 조준 방향으로 Raycast2D를 쏘고, 처음 맞은 대상에 피해를 준다. 벽은 관통하지 않는다. 샷건은 펠릿 8개를 부채꼴로 쏜다. 광선검은 앞쪽 120° 부채꼴 범위 판정을 쓴다.
2. **탄퍼짐**: 조준 방향에 ±(현재 퍼짐 각도) 범위의 무작위 각을 더한다. 이동 중에는 2배. 저격총은 우클릭 조준 시 0.5°.
3. **반동**: 한 발 쏠 때마다 퍼짐 각도가 누적되고, 쏘지 않으면 초당 일정량씩 회복된다. 화면에는 카메라 흔들림으로 표현한다.
4. **탄창과 재장전**: 탄창이 비면 쏠 수 없다. R키로 재장전하며, 재장전 중에는 사격 불가에 이동 속도가 줄어든다. 예비 탄약은 루팅으로만 얻는다. 광선검은 탄이 없다.
5. **체력과 피격**: 플레이어 HP 100, 자동 회복 없음. 피격 시 캐릭터가 하얗게 번쩍이고(0.1초) 바닥에 혈흔이 남으며 0.2초 경직된다. 로봇은 맞으면 혈흔 대신 불꽃이 튄다. 회복은 메디젤·메디킷으로만 가능하다.
6. **구르기**: Space로 이동 방향으로 3칸 빠르게 구른다. 0.4초 동안 무적, 쿨타임 3초. 재장전 중에 구르면 재장전이 취소된다.
7. **방어력**: `받는 피해 = 공격 피해 × (1 − 방어력 × 0.04)`. 방어력 1당 4% 감소, 최대 방어력 12에서 48% 감소. 고정값을 빼는 방식은 약한 공격이 0이 되므로 쓰지 않는다.

## 5. 적 AI

적은 보안 로봇 하나의 상태 머신을 쓰고, 든 무기에 따라 5종으로 나눈다. 플레이어와 같은 무기 데이터를 쓰되 피해는 약 절반으로 낮추고 사격 사이에 쉬는 시간을 넣는다. 강한 공격 전에는 충전이나 조준선을 보여줘서 구르기로 피할 타이밍을 준다.

### 5.1 상태

- **순찰**: 지정된 웨이포인트 2~3개를 순서대로 걸어 다닌다. 플레이어가 시야에 들어오면 경계로.
- **경계**: 멈춰서 0.6초 동안 플레이어 쪽을 본다(머리 위 "!" 표시). 계속 보이면 사격, 사라지면 추격.
- **사격**: 사거리 안이고 시야가 뚫려 있으면 사격 패턴대로 공격한다.
- **추격**: 마지막으로 본 위치까지 이동한다. 5초 동안 못 찾으면 순찰로 복귀.
- 총소리를 듣거나 피격되면 상태와 관계없이 그 위치로 추격한다.

### 5.2 시야 판정

아래 세 조건을 모두 만족해야 "보인다".

1. 플레이어까지 거리 ≤ 시야 거리
2. 바라보는 방향과의 각도 ≤ 시야각의 절반
3. 그 사이에 벽이 없음 (Raycast2D)

## 6. 루팅과 가방

### 6.1 가방 화면 (Tab)

화면 구성은 위에서 아래로 다음과 같다.

- **내 캐릭터 칸 (위쪽)**: 헬멧 칸 1개, 우주복(방탄복) 칸 1개, 무기 슬롯 1개.
  - 무기는 종류 제한 없이 무엇이든 장착할 수 있지만 한 번에 하나만 든다. 다른 무기는 가방에 넣어 두었다가 드래그로 바꾼다.
  - 장비 칸에 있는 것은 가방 칸을 차지하지 않는다.
- **가방 (아래쪽)**: 칸 배치 방식.
  - 기본 가방: 가로 3 × 세로 4 (12칸)
  - 우주복 추가 칸: 기본 가방 바로 아래에 붙는다. 단계별 3×1 / 3×2 / 3×3. 3단계를 입으면 가방은 3×7 (21칸).
  - 보관함: 기본 가방 바로 오른쪽에 1×1 칸 1개. 여기 넣은 아이템은 죽어도 절대 잃지 않는다.
- 아이템마다 크기(가로×세로)가 있고, 가방을 연 상태에서 R로 회전한다.
- 탄약은 같은 종류끼리 한 칸에 최대 60발까지 쌓인다.

### 6.2 루팅

- 컨테이너에 다가가 E키를 1초 누르고 있으면 열린다. 여는 동안 맞으면 취소된다.
- 열면 **그 오브젝트 바로 위에 루팅 칸**이 뜨고 가방 화면도 함께 열린다. 아이템을 가방·장비 칸의 원하는 자리로 **드래그**해서 가져온다. 자동으로 가방에 들어가는 아이템은 없다.
- 파괴된 로봇도 같은 방식으로 뒤진다. 로봇은 자기 무기의 탄약을, 가끔 무기나 방어구를 떨어뜨린다.

| 루팅 대상 | 루팅 칸 크기 | 위치 |
| --- | --- | --- |
| 일반 컨테이너 | 3×2 | 화물칸 |
| 연구 컨테이너 | 3×3 | 연구 구역 (보안 로봇 근처) |
| 파괴된 로봇 | 3×1 | 쓰러진 자리 |

### 6.4 무게와 이동 속도

- 최대 무게는 20kg. 장착한 무기·방어구 무게도 포함한다.
- 최대 무게의 50%가 차면 이동 속도 20% 감소, 이후 10%마다 10%씩 추가 감소.
- 이동 속도 하한은 20% (초기값).
- 최대 무게의 150%를 넘으면 초당 HP 0.5 감소.

| 무게 (최대 대비) | 무게 (kg) | 이동 속도 (기본 대비) |
| --- | --- | --- |

## 7. 레이드 규칙

- **진입**: 대기실 창고에서 장비를 골라 정거장에 도킹한다. 시작 장비는 따로 주지 않는다. 게임을 처음 시작할 때 대기실 창고에 기본 세트(레이저 피스톨 + 권총 에너지 셀 24발 + 광선검) 3세트가 들어 있다.
- **산소**: 기본 8분(헬멧으로 최대 11분). 남은 1분부터 게이지가 빨간색으로 깜빡인다.
- **산소 고갈**: 산소가 0이 되면 초당 HP 5의 질식 피해를 입는다(HP 100 기준 20초 뒤 사망). 산소 캔을 쓰면 즉시 멈춘다.
- **탈출 포드**: 정거장에 2곳. 레이드 시작 시 1곳만 무작위로 작동한다. 화면에 방향은 표시하지 않고, M키 전체 맵에서만 비상구 모양으로 보인다.
- **탈출 조건**: 포드 안에서 5초 동안 발사 준비. 밖으로 나가면 카운트가 초기화되고, 맞아도 카운트는 계속된다. 카운트다운은 포드 위에 숫자로 표시한다.
- **탈출 성공**: 가방과 장비를 가지고 대기실 창고로 돌아간다.
- **사망**: 장착한 무기·방어구와 가방 안의 것을 전부 잃는다. 보관함 1칸의 아이템만 남는다. 결과 화면에 잃은 가치를 보여준다.
- **대기실 창고**: 레이드 사이의 화면. 5×10(50칸) 칸 배치 창고. 보유 아이템과 총 가치(점수 역할)를 보여주고 JSON 파일로 저장한다. 판매·상점은 없다.

## 8. 맵, 조작, HUD

### 8.1 맵

타일맵으로 만든 맵 1개(약 60×40 칸).

- **구역**: 도킹 구역(남쪽, 진입) → 화물칸(중앙, 일반 컨테이너 다수) → 연구 구역(북쪽, 연구 컨테이너 + 보안 로봇 밀집) → 탈출 포드 2곳(동쪽 끝, 서쪽 끝)
- **배치**: 보안 로봇 6~8기, 일반 컨테이너 8개, 연구 컨테이너 2개. 격벽과 화물로 시야와 사격을 막는다.
- **로봇 수는 구역마다 다르게 설정한다.** 구역별 로봇 수와 종류는 맵 데이터에 적어서 Inspector에서 바꿀 수 있게 한다.

| 구역 | 로봇 (초기값) |
| --- | --- |
| 화물칸 | 근접·권총 로봇 2~3기 |
| 연구 구역 | 4~5기 (근접·권총 + AR·저격·샷건) |

### 8.2 전체 맵 (M키)

- 가 본 곳만 보인다.
- 내 위치를 표시한다.
- 한 번 가 본 곳은 다음 판에도 계속 보인다(저장).
- 탈출 포드는 비상구 모양 아이콘으로 표시한다.

### 8.3 조작

| 조작 | 키 |
| --- | --- |
| 이동 / 구르기 | WASD / Space |
| 조준 / 사격 | 마우스 / 좌클릭 (저격총은 우클릭 조준) |
| 무기 교체 | 가방(Tab)에서 드래그 |
| 재장전 | R |
| 컨테이너 열기 | E (길게 누르기) |
| 도구칸 사용 | 1, 2, 3 |
| 가방 / 아이템 회전 | Tab / 가방을 연 상태에서 R |
| 전체 맵 | M |

### 8.4 HUD 배치

- **왼쪽 아래**: HP, 산소, 가방 무게를 구 모양 게이지 3개로 배치.
- **하단 중앙 무기칸**: 장착한 무기 1칸. 그 위에 탄창 / 예비탄 수를 작게 표시.
- **하단 중앙 도구칸 1, 2, 3**: 메디젤·메디킷·산소 캔 중 원하는 것을 칸 구분 없이 등록. 구르기를 했을 때만 도구칸 위에 구르기 쿨타임 표시.
- **탈출 포드**: 화면에 방향 표시 없음. 탈출 카운트다운은 포드 위에 숫자로 표시.
- **피격 효과**: 캐릭터가 하얗게 번쩍(0.1초)하고 바닥에 혈흔이 남음. 로봇이 맞을 때는 혈흔 대신 불꽃 효과.
