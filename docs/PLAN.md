## 에셋 생성 방식

- Unity 메뉴 `EscapeFromSpace > 에셋 생성·갱신`이 스프라이트, 타일, SO 에셋, 프리팹, 씬을 만든다.
- 이미 있는 에셋은 덮어쓰지 않는다. 없는 에셋, 없는 컴포넌트, 비어 있는 참조만 채운다. Inspector에서 바꾼 값과 손으로 고친 타일맵은 그대로 남는다.
- 기획서 초기값은 에셋을 처음 만들 때만 넣는다.

# 2부: 11/15 작업 (질문 확정, 6단계 구현 대기)

범위는 GDD 10장 일정의 11/15 "무기 5종"이다: 반동·탄퍼짐·재장전, 샷건 펠릿, 광선검 범위 판정, 무기 5종 수치 입력.

로봇(11/16), 가방·루팅·탄약 아이템(11/17), HUD(11/19)는 여기서 만들지 않는다.

## GDD에서 그대로 따르는 규칙

질문 없이 GDD 4.1과 4.2대로 구현한다.

- **탄퍼짐**: 조준 방향에 ±(현재 퍼짐 각도) 범위의 무작위 각을 더한다. 이동 중에는 2배.
- **반동**: 한 발 쏠 때마다 퍼짐 각도가 누적되고, 쏘지 않으면 초당 일정량씩 회복된다. 화면에는 카메라 흔들림으로 표현한다.
- **탄창과 재장전**: 탄창이 비면 쏠 수 없다. R키로 재장전한다. 재장전 중에는 사격 불가에 이동 속도가 줄어든다. 광선검은 탄이 없다.
- **구르기**: 재장전 중에 구르면 재장전이 취소된다.
- **샷건**: 펠릿 8개를 부채꼴로 쏜다. 펠릿마다 따로 판정하고 명중점을 표시한다.
- **광선검**: 앞쪽 120° 부채꼴, 사거리 1.8칸의 범위 판정.
- **저격총**: 우클릭 조준 시 퍼짐 0.5°.
- **사격 입력**: 모든 무기가 좌클릭을 누르고 있으면 연사 속도로 계속 발사 (1부 결정 8번).
- **무기 수치**: GDD 4.2 표의 초기값을 `WeaponData` 에셋 5개에 넣는다.

GDD에 값이나 규칙이 비어 있는 부분이다. "추천" 열이 제안이다. 답을 받기 전에는 구현하지 않는다.

| 6 | 재장전 중 이동 속도는 얼마나 줄어드는가? | 50%. `PlayerData`에 둔다. |

| 10 | 피격 경직 중에 재장전은 계속되는가? | 계속된다. 취소는 구르기만 한다. |

| 16 | 저격총 우클릭 조준은 퍼짐 외에 다른 효과가 있는가? (이동 속도, 화면 확대 등) | 없다. 우클릭을 누르는 동안 기본 퍼짐만 6° → 0.5°로 바뀌고, 반동 누적과 이동 중 2배는 그대로 적용한다. |

| 추가 | 사격 궤적 선 | 탄퍼짐을 눈으로 확인하려고 총구에서 탄이 닿은 곳(빗나가면 사거리 끝)까지 궤적 선을 잠깐 표시한다. 명중점 동그라미, 혈흔, 불꽃은 그대로 둔다. 1부 결정 9번과 GDD 4.1의 "궤적 선 없음"을 바꾼 것이다 |

- 6번: "30%"를 "30% 감소"로 해석했다. 30% 속도로 느려지라는 뜻이면 배율을 0.3으로 바꾼다 (Inspector 값이라 코드 수정 없음).

탄창과 예비탄 수는 HUD(11/19)가 생기기 전까지 `PlayerShooter`의 Inspector 칸으로 확인한다 (1부의 Current Hp와 같은 방식).
